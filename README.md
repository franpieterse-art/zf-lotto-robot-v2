# ZF Lotto Robot V35 — Consensus + Diversity Experiment

Novel-for-this-project formula: four historical lookback windows (18, 45, 110, 260 draws), with smoothed exposure-adjusted frequency, z-score consensus, and shrinkage when windows disagree. Ten unique rows are then generated with penalties for repeating numbers and number pairs across the rows. All eligible numbers are available; no exclusions. The model uses only Main Lotto draws before the selected prediction date. Predict, Reveal, Compare and backtest remain in place. Predict does not call outside sites.

This is not claimed to be an invention no one else has tried; no historical formula can reliably improve the per-line probability of an independent fair lottery. Portfolio diversity changes coverage across ten tickets, not the odds of each individual line.

Install: extract, replace GitHub files, commit, redeploy Render, Ctrl+F5.
